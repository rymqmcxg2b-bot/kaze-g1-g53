# Security Policy

This is a sanitized educational archive, not an active trading deployment.

## Please do not publish

- API tokens, private keys, seed phrases, session cookies, or signed URLs;
- account, wallet, order, fill, or trade identifiers;
- cloud account/resource identifiers, private endpoints, or deployment receipts;
- live positions, balances, entry prices, or other private account state;
- code or configuration that grants exchange-write authority.

If you find something that looks sensitive, please do not open a public issue containing the value. Use GitHub private vulnerability reporting when it is available. Otherwise, do not disclose the value publicly; contact the repository owner through a non-public channel.

The examples in this repository deliberately include no network transport, credential loader, exchange adapter, or order-submission capability.
